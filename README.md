
# Sistema de Assinaturas e Mensalidades

## Sobre o projeto

Sistema desenvolvido em Python para gerenciamento
de clientes, planos e assinaturas.

A aplicação utiliza dicionários para armazenar
os dados em memória e Tkinter para construir
uma interface gráfica.

## Funcionalidades

- Cadastro de clientes
- Cadastro de planos
- Pesquisa de clientes
- Criação de assinaturas
- Atualização de assinaturas
- Dashboard
- Relatórios e listagem de registros

## Tecnologias utilizadas

- Python
- Tkinter
- GitHub
- Git

## Estrutura do projeto

- main.py
- database.py
- dashboard.py
- clientes_planos.py
- assinaturas.py
- relatorios.py

## Como executar

1. Instale o Python.
2. Baixe o repositório.
3. Abra a pasta no Visual Studio Code.
4. Execute o arquivo main.py.

## Armazenamento

Os dados são armazenados em dicionários
durante a execução do programa.

Ao fechar a aplicação, os dados são perdidos.

## Organização

O projeto utiliza branches para separar
as responsabilidades de desenvolvimento
e Pull Requests para integrar as funcionalidades.
