Colaborativa com Gabriel e Felipe

Sistema de Faturamento e Assinaturas de Clientes
Projeto desenvolvido em Python para gerenciar o faturamento e as assinaturas de clientes, utilizando dicionários como banco de dados em memória.

O sistema permite realizar o cadastro de clientes e planos, criar e atualizar assinaturas, pesquisar clientes e listar todos os dados cadastrados. Também conta com validações de entrada e tratamento de exceções para garantir maior segurança durante as operações.

Principais funcionalidades:

Cadastro de clientes.
Cadastro de planos com valores e duração.
Criação de assinaturas vinculadas a clientes e planos.
Cálculo automático do valor total da assinatura.
Pesquisa de clientes pelo ID.
Atualização de assinaturas.
Listagem de clientes, planos e assinaturas.
